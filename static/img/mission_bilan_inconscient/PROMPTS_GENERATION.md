# Prompts pour Génération d'Images - Mission Bilan de l'Inconscient

## Guide d'utilisation

Ces prompts sont optimisés pour les générateurs d'images IA (Midjourney, DALL-E 3, Stable Diffusion, etc.).

**Conseils :**
- Utilisez un ratio 16:9 ou 4:3 pour les scènes
- Style réaliste et professionnel
- Évitez les éléments graphiques ou texte dans l'image
- Privilégiez la lumière naturelle du jour

## 💡 Conseils de Génération

### Pour Midjourney
Ajoutez à la fin de chaque prompt :
```
--ar 16:9 --style raw --v 6
```

### Pour DALL-E 3
- Utilisez le prompt tel quel
- Demandez "photorealistic" ou "illustration" selon le type d'image
- Ratio : Landscape (1792x1024) pour les scènes

### Pour Stable Diffusion
Ajoutez les paramètres :
```
Negative prompt: cartoon, anime, low quality, blurry, text, watermark
Steps: 30-50
CFG Scale: 7-9
Sampler: DPM++ 2M Karras
```

## 🔄 Itération

Si les images générées ne correspondent pas :
- **Trop sombre** : Ajoutez "bright natural daylight, well-lit"
- **Pas assez réaliste** : Ajoutez "photorealistic, 8k, professional photography"
- **Mauvais angle** : Précisez "front view", "side view", "close-up", etc.
- **Éléments manquants** : Listez explicitement tous les éléments importants

Bonne génération ! 🎨
